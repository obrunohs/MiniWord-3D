MiniWorld 3D Habbo v14 - Trade sincronizado

Ajustes desta versão:
- Quando os dois jogadores confirmam a troca, a janela fecha para os dois.
- Se um jogador clicar no X, o trade é cancelado para os dois e aparece aviso dizendo quem cancelou.
- O jogador pode adicionar várias unidades do mesmo mobi no trade clicando várias vezes no item do inventário.
- Cada item oferecido tem um X para remover uma unidade da troca.
- Trocar de aba no navegador não remove mais o personagem do quarto.
- A presença ainda é removida ao fechar/recarregar a página.
